# MHGeek

MHGeek 是供 AInice视觉空间传感器 接入米家极客版的非官方插件，当前版本为 **1.0.0**。插件通过手机号短信授权连接主中枢，将全局及 A～H 区状态同步到米家极客版，供自动化使用。

## 使用

在 AInice视觉空间传感器 的插件管理页面导入 `.plugin` 安装包。完成短信授权后，填写主中枢的 IPv4 地址并绑定；在插件页面设置事件名称和无人持续时间，保存后自动同步。
